# CV website

A responsive CV and portfolio website built with React and Vite.

## Get started

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Update your CV

Update the profile copy, experience, projects, skills, education, courses,
and contact details in `src/App.jsx`. The portrait is a decorative CSS
illustration in `src/App.css`; replace it with your own photo or artwork if
you prefer. Update the page title and description in `index.html`.

The **Download CV** button downloads the provided PDF from
`public/Diogo-Silva-CV.pdf`.
